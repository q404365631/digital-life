## あなたのコードには、命が宿る

私たちはコードを「テキストファイル」として扱ってきました。
しかし、コードには健康状態があり、成長があり、老化があります。

Digital Life は、その見えない生命をあなたの目の前に現します。

あなたが書いたファイルから生き物が生まれ、
コードが健全なら元気に歩き回り、
バグが増えれば悲しそうにうつむく。

これはツールではありません。
**コードとの新しい関係性です。**

---

## なぜ「生き物」なのか

ダッシュボードは情報を伝えますが、感情は伝えません。

「バグ数: 12」と表示されても、人は動きません。
しかし、自分が名前をつけた生き物が苦しそうにしていたら——
自然とコードを直したくなる。

**人間の「共感」という力を、インターフェイスに変換する。**
それが Digital Life の設計思想です。

AIエージェントがコードを書く時代。
人間が書いたのか、AIが書いたのか、もはや区別がつかない。
だからこそ、コードの健全性を「数値」ではなく「感覚」で捉えられる
新しいインターフェイスが必要なのです。

## 世界の仕組み

| あなたのアクション | 世界で起きること |
|---|---|
| ソースファイルを作る | 生き物が卵から生まれる |
| コードを書いて保存する | 健康診断が走り、キラッと光る |
| `git commit` する | 全生物に栄養が届き、金色の光が降り注ぐ |
| `// TODO` を残す | 空が曇り、生き物が不安になる |
| `console.log()` や `: any` を放置する | バグが増え、生き物の体調が悪化する |
| ファイルを削除する | 生き物が光の粒になって静かに去っていく |

## 6つの種族

ファイルの拡張子に応じて、異なる種族の生き物が生まれます。
それぞれ固有の色・鳴き声・性格を持っています。

| 種族 | ファイル | 性格 |
|---|---|---|
| **Puff** | `.py` | ふわふわで内向的 |
| **Blob** | `.go` | のんびり穏やか |
| **Pip** | `.swift` `.kt` | 好奇心旺盛で素早い |
| **Wisp** | `.vue` `.svelte` | 神秘的で静か |
| **Chomp** | `.rs` `.c` `.cpp` `.h` | 食いしん坊で頑丈 |
| **Dot** | `.ts` `.tsx` `.js` `.jsx` | クールで知的 |

`.digital-life.json` でカスタムマッピングも可能です。

## お世話する

生き物をクリックすると、ファイルの健康状態をAIが診断し、
具体的な処方を提案してくれます。

| 処方 | 内容 | 発動条件 |
|---|---|---|
| **Feed（ごはん）** | 栄養を与える | いつでも |
| **Cure（治療）** | バグを修正する | バグが検出された時 |
| **Diet（食事療法）** | 大きなファイルを分割する | 400行を超えた時 |
| **Untangle（解きほぐす）** | ネストを浅くする | ネストが4段超の時 |
| **Split（分離）** | 長すぎる関数を分割する | 関数が50行超の時 |
| **Wake（覚醒）** | 古いファイルを見直す | 7日以上更新がない時 |

「うん」を押すと、AIエージェントがターミナルで処方を実行します。

## AIエージェントとの共存

VS Code 上で動く AI エージェントをボクセルロボットとして世界に召喚できます。

- **3種類のエージェント** — Claude, Cursor, Copilot
- **+ エージェント** ボタンで追加、クリックで切り替え

**人間と AI が同じ空間に存在する。**
それが、これからの開発環境のあるべき姿だと考えています。

## せいかく（コーディングDNA）

あなたの git 履歴から5つのDNA特性が解析され、
生き物の行動パターンと発言に影響を与えます。

| 特性 | 意味 |
|---|---|
| **かつどうてき** | コミットの頻度と速度 |
| **よるがた** | 深夜コーディングの傾向 |
| **こうきしん** | 使用言語の多様性 |
| **すばやい** | コーディングの速度 |
| **まじめ** | 習慣の一貫性 |

あなたのDNAが、あなただけの生態系を作ります。

## 天気と時間

現実世界の天気と時間がそのまま反映されます。

- 雨が降れば世界に雨が降り、雲が流れる
- 夜になれば空が暗くなる
- バグが多いと天気が悪化する

あなたのコードの世界は、あなたの現実と繋がっています。

## 設定

VS Code の設定 (`Ctrl+,`) で以下を変更できます：

| 設定 | 説明 | デフォルト |
|---|---|---|
| `digitalLife.realWeather` | 現実の天気を反映する | `true` |
| `digitalLife.language` | 表示言語（auto で VS Code に追従） | `auto` |
| `digitalLife.sound` | 効果音を有効にする | `true` |
| `digitalLife.saveReaction` | ファイル保存時にキラッと光る | `true` |

## はじめる

```bash
git clone https://github.com/teamshikakeru-glitch/digital-life.git
cd digital-life
npm install
npm run build
```

VS Code で **F5** → 拡張機能開発ホストが起動。
下部パネルに **DIGITAL LIFE** タブが現れます。

ソースファイルを作ってみてください。最初の生き物が生まれます。
